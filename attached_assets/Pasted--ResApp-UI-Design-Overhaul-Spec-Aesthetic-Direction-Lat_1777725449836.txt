# ResApp — UI Design Overhaul Spec
 
## 🎯 Aesthetic Direction: "Late-Night Street Food — Warm Brutalism"
 
Not Swiggy. Not Zomato. Something rawer.
Inspired by the visual language of hand-painted restaurant signboards, street stall neon, and Indian menu cards — but rendered clean and digital.
 
**Feeling**: Warm, tactile, opinionated. Like a restaurant that has personality.
**NOT**: Purple gradients, Inter font, card shadows on white backgrounds, generic food-tech blue.
 
---
 
## 🎨 Color Palette
 
```
--color-bg:         #0F0D0B   /* near-black, warm undertone */
--color-surface:    #1A1714   /* card background */
--color-surface-2:  #231F1A   /* elevated surface */
 
--color-primary:    #F4A623   /* turmeric amber — main accent */
--color-primary-dim:#C4821A   /* darker amber for hover */
--color-hot:        #E8421A   /* chili red — for CTAs, badges */
--color-fresh:      #5BB57A   /* coriander green — for success, veg icon */
 
--color-text:       #F5EFE6   /* warm off-white */
--color-text-muted: #8A7E70   /* warm gray */
--color-border:     #2E2820   /* subtle divider */
 
--color-shimmer-1:  #1E1B17
--color-shimmer-2:  #2A2520
```
 
**Why this works**: Dark + warm amber reads as premium street food, not SaaS. The chili red gives urgency to CTAs without being generic. Green feels natural for veg/fresh indicators.

## ☀️ Light Theme — "Warm Paper / Chai Morning"
 
Soothing, earthy, and soft. Think handmade paper, terracotta, and natural linen — not clinical white. This light mode should feel like a cozy café menu, not a hospital form.
 
**Feeling**: Calm, approachable, warm. Eye-friendly even in bright rooms.
**NOT**: Pure white backgrounds, cold grays, harsh contrast.
 
### Light Theme Color Tokens
 
```css
[data-theme="light"] {
  --color-bg:         #FAF6F1   /* warm linen — NOT pure white */
  --color-surface:    #FFFFFF   /* card surface, slightly cooler than bg */
  --color-surface-2:  #F2EDE6   /* input fields, tags background */
 
  --color-primary:    #C97B2B   /* deeper amber — more readable on light */
  --color-primary-dim:#A86220   /* hover state */
  --color-hot:        #D94418   /* slightly deeper chili red on light */
  --color-fresh:      #3D9A60   /* deeper green for light bg */
 
  --color-text:       #1F1A14   /* warm near-black, NOT #000 */
  --color-text-muted: #7A6E63   /* warm medium gray */
  --color-border:     #E4DDD4   /* soft warm gray border */
 
  --color-shimmer-1:  #EDE8E1
  --color-shimmer-2:  #F7F3EE
}
```

### Light Theme Component Adjustments
 
**Header:**
- Background: `#FAF6F1` (same as bg), bottom border `1px solid --color-border`
- Logo: amber `#C97B2B`
- Search bar: `#F2EDE6` background, amber focus ring
- Cart button: `#D94418` background stays the same
**Restaurant Cards:**
- Background: `#FFFFFF`
- Border: `1px solid #E4DDD4`
- On hover: border turns `#C97B2B`, card lifts `translateY(-4px)`
- Add subtle `box-shadow: 0 4px 16px rgba(0,0,0,0.06)` on hover ONLY (not default state)
- Rating chip: amber background `#C97B2B`, white text
**Search Bar:**
- Background: `#F2EDE6`, border `1px solid #E4DDD4`
- Focus ring: `2px solid #C97B2B`
**Shimmer (light):**
- Gradient from `#EDE8E1` to `#F7F3EE` — warm, not gray
**Section Titles:**
- Text: `#1F1A14`
- Amber underline accent stays the same
### Theme Toggle Implementation
 
Add a toggle button in the Header. Use `data-theme` on `<html>` or `<body>`:
 
```js
// In Header.js
const toggleTheme = () => {
  const current = document.documentElement.getAttribute('data-theme');
  document.documentElement.setAttribute('data-theme', current === 'light' ? 'dark' : 'light');
  localStorage.setItem('theme', current === 'light' ? 'dark' : 'light');
};
 
// On app load
const saved = localStorage.getItem('theme') || 'dark';
document.documentElement.setAttribute('data-theme', saved);
```
 
```css
/* In index.css */
:root {
  /* dark theme defaults */
  --color-bg: #0F0D0B;
  /* ... all dark tokens */
}
 
[data-theme="light"] {
  --color-bg: #FAF6F1;
  /* ... all light tokens */
}
```
 
Toggle button style: small pill, sun/moon icon, positioned right of search in navbar. Uses `--color-surface-2` background with `--color-text-muted` icon.

## ❌ Light Theme Specific DON'Ts
 
| Don't | Do Instead |
|---|---|
| Pure white `#FFFFFF` background | Warm linen `#FAF6F1` |
| Cold gray `#9CA3AF` muted text | Warm gray `#7A6E63` |
| Blue links/accents | Amber `#C97B2B` throughout |
| Heavy box shadows by default | Border-only default, shadow on hover only |
| Gray shimmer | Warm `#EDE8E1 → #F7F3EE` shimmer |
| High contrast harsh borders `#D1D5DB` | Soft warm border `#E4DDD4` |

## 🔤 Typography
 
```
--font-display: 'Dela Gothic One', cursive;   /* headers, brand name — bold, Japanese-influenced */
--font-body:    'DM Sans', sans-serif;         /* readable, slightly quirky — not Inter */
--font-mono:    'JetBrains Mono', monospace;   /* prices, counts */
```
 
**Load from Google Fonts:**
```html
<link href="https://fonts.googleapis.com/css2?family=Dela+Gothic+One&family=DM+Sans:wght@300;400;500;600&family=JetBrains+Mono:wght@400;600&display=swap" rel="stylesheet">
```
 
**Type Scale:**
- H1 (brand/hero): `Dela Gothic One`, 3.5rem, letter-spacing -1px
- H2 (section titles): `Dela Gothic One`, 2rem
- Card title: `DM Sans 600`, 1rem
- Body/desc: `DM Sans 400`, 0.875rem
- Price: `JetBrains Mono 600`, 1rem, `--color-primary`

## 🧱 Component Specs
 
### Header / Navbar
- Background: `--color-bg` with bottom border `1px solid --color-border`
- Logo: Brand name in `Dela Gothic One`, amber colored
- Location selector: Small pill with pin icon, muted text, subtle border
- Search bar: Dark input (`--color-surface-2`), amber focus ring, no white backgrounds
- Cart button: `--color-hot` background, white text, `JetBrains Mono` for item count
- No box-shadow navbar — use border only
### Restaurant Cards
- Background: `--color-surface`
- Border: `1px solid --color-border`
- Border-radius: `12px` (not round, not sharp)
- On hover: border color shifts to `--color-primary` (amber), subtle `translateY(-4px)` lift
- Cuisine tags: small pill badges, `--color-surface-2` background, amber text
- Rating chip: amber background, dark text (like a stamp), top-right of image
- Delivery time: chili red text, small icon
- **No drop shadows on cards** — use border highlight on hover instead
### Restaurant Image
- Aspect ratio: `16/9`, `object-fit: cover`
- On hover: slight scale `1.03` on the image only (overflow hidden on wrapper)
- Optional: thin amber gradient overlay at bottom of image
### Search Bar
- Full-width in body section OR in header
- Dark bg (`--color-surface-2`), amber icon, `--color-text` placeholder
- Focus: amber outline `2px solid --color-primary`
### Cart Sidebar / Page
- Background: `--color-surface`
- Item rows: left image, name in `DM Sans 600`, price in `JetBrains Mono`
- Quantity controls: small, rounded, border `--color-primary`
- Total row: bigger, amber colored price
- Checkout button: full-width, `--color-hot` background, white `DM Sans 600` text
### Shimmer / Loading Skeleton
- Use `--color-shimmer-1` and `--color-shimmer-2` for gradient animation
- No white/gray default shimmer — keep it dark-themed
- Shimmer cards should match the exact shape of restaurant cards
### Veg / Non-Veg Badges
- Veg: green square outline + green dot (standard FSSAI style) — `--color-fresh`
- Non-veg: brown square outline + brown dot
### Menu Item Cards
- Minimal — left text, right image (small thumbnail)
- Price in amber mono
- Add button: outlined style, turns filled amber on click
- Divider line between items: `1px solid --color-border`

## 📐 Layout & Spacing
 
```
--spacing-xs:  4px
--spacing-sm:  8px
--spacing-md:  16px
--spacing-lg:  24px
--spacing-xl:  40px
--spacing-2xl: 64px
 
--radius-sm:   6px
--radius-md:   12px
--radius-lg:   20px
--radius-pill: 999px
```
 
- Main container max-width: `1280px`, centered
- Card grid: `repeat(auto-fill, minmax(280px, 1fr))`, gap `24px`
- Section title left-aligned, NOT centered
- Section title has a small amber underline accent (3px wide, 40px long, bottom)

## ✨ Micro-interactions & Animation
 
- Card hover: `transition: all 200ms ease-out` — border color + slight lift
- Add-to-cart button: scale pulse on click (`transform: scale(0.95)` then back)
- Cart count badge: `keyframes bounce` when item added
- Page load: cards fade in staggered with `animation-delay: calc(index * 60ms)`
- Shimmer: `background: linear-gradient(90deg, shimmer-1, shimmer-2, shimmer-1)` with `background-size: 200%` and `animation: shimmer 1.4s infinite`

## ❌ What to AVOID (Generic AI Traps)
 
| Don't | Do Instead |
|---|---|
| Pure white background (light) | Warm linen `#FAF6F1` |
| Pure black background (dark) | Warm near-black `#0F0D0B` |
| Purple/blue gradients | Amber + chili red accents |
| Inter / Roboto | Dela Gothic One + DM Sans |
| Box shadows everywhere | Border highlights on hover |
| Flat gray shimmer | Dark-toned warm shimmer |
| Centered section headers | Left-aligned with amber accent |
| Generic green buttons | Amber (add) + red (checkout) |
| Rounded pill cards | Subtle 12px radius cards |
